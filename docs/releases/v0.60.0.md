# v0.60.0：翻譯核心重寫

這一版重寫了翻譯引擎與斷句。字幕外觀、拖曳、播放器按鈕與設定頁維持原樣。

## 你會注意到的改變

- **繁簡中文不再混用。** 目標設為繁體中文時，不論自動切換到哪個翻譯來源，譯文都是繁體；簡體亦然。
- **譯文更完整。** 手動字幕會先合併成完整句子再翻譯；`Mr.`、`U.S.` 這類縮寫不再把一句話切斷。
- **當前字幕更快出現。** 畫面上的字幕會插隊到背景預取前面；某個來源失敗時直接改用下一個來源。
- **靜音段落不再殘留舊字幕。**
- **英文影片配英文目標語言**時只顯示原文，不送出翻譯請求。
- **暫停後回來不必重翻。** 已翻譯的句子保存在本機，可在設定頁「清除翻譯快取」一鍵刪除。
- 修正 Google Dictionary 來源的譯文後面多出 `en`。
- 修正 MyMemory 額度用盡時，把警告文字當成字幕顯示。

## 翻譯來源順序

自動免費模式改為：Google Free → Microsoft Edge → Google Dictionary → Lingva → LibreTranslate → MyMemory。

Microsoft 的免費授權端點在 2026 年 10 月測試時回傳 404。外掛偵測到 404 會讓該來源休息 30 分鐘，不會拖慢每一句字幕。

## 隱私

新增的翻譯快取只存在你自己的瀏覽器（extension storage），不會上傳。沒有新增權限或外部服務。
