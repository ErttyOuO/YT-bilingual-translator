# v0.61.0：DeepL、Microsoft 官方 API 與本機翻譯

## 新的翻譯來源

- **DeepL API（自備 Key）**：品質優先。免費方案每月 50 萬字元，繁體／簡體都支援。
- **Microsoft Translator（Azure，自備 Key）**：官方 API，免費層每月 200 萬字元。
- **本機翻譯（Bergamot）**：在 Firefox 內翻譯，字幕不會送到任何伺服器。使用和 Firefox 內建翻譯相同的模型，英文→繁體中文、英文→簡體中文都有。

## 本機翻譯怎麼用

1. 設定頁 →「翻譯」→ 翻譯方式選「本機翻譯 Bergamot」。
2. 按「準備本機模型」，在 Firefox 的提示中允許下載。
3. 等狀態顯示「本機翻譯已就緒」（第一次約下載 50 MB）。

注意：
- 翻譯時約占用 300–600 MB 記憶體。
- 需要 YouTube 字幕軌的語言資訊；Twitch 目前無法使用本機翻譯。
- 預設失敗時不會改用雲端翻譯；如果需要，可以勾選「本機翻譯失敗時改用免費雲端翻譯」。

## 其他變更

- 免 Key 模式改為 Google Free → Google Dictionary → MyMemory。移除已失效的 Microsoft Edge 免費端點；原本選它的設定會自動改成免 Key 模式。
- DeepL、Azure、模型下載需要的網站權限改成「選用權限」，只有選擇該翻譯來源時才會詢問。更新本版不會出現權限提示。
- 本機翻譯的中文標點會轉成全形。
